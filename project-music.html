Project 03

Music Taste Analyzer

A personal listening dashboard that explores genre patterns, repeat artists, mood shifts, and how music taste changes over time.

Role Data analyst, visualization designer
Tools Python, pandas, Spotify API, Plotly
Status Planned summer build

Case study outline

Question

What does my listening history reveal about mood, routines, favorite eras, and how my taste changes over time?

Data

Spotify listening history, artist metadata, genres, audio features, saved tracks, playlists, and timestamps.

Output

An interactive dashboard plus a short writeup on listening patterns, genre drift, repeat behavior, and recommendation insights.
