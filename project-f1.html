Project 01

F1 Race Strategy Dashboard

A motorsport analytics project exploring whether pace, tire degradation, and pit timing explain race outcomes across drivers and constructors.

Role Data analyst, dashboard designer
Tools Python, pandas, SQL, Plotly, Streamlit
Status Planned summer build

Case study outline

Question

Which race decisions create the largest performance swing: tire choice, pit window, qualifying position, or raw pace?

Data

Race results, lap times, pit stops, tire stints, weather context, and constructor/driver metadata.

Output

A dashboard with driver comparisons, race timelines, strategy deltas, and a short written analysis of the clearest findings.
