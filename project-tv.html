Project 02

Watchlist Product Lab

A TV-focused watch journal inspired by Letterboxd, designed as both a product build and a dataset for understanding viewing habits.

Role Product builder, data modeler
Tools React, SQL, API data, analytics dashboard
Status Scoping

Case study outline

Question

How can a TV logging app support season-aware reviews, friend activity, and useful recommendations without becoming cluttered?

Data

User ratings, watch dates, show metadata, genres, completion rate, review tags, and watch gaps between seasons.

Output

A usable web app plus an analytics writeup on viewing behavior, retention patterns, and recommendation signals.
